# Aktyvių veiklų registracija

Platforma, kurioje organizatoriai gali kurti veiklas, o dalyviai – rezervuoti ir atšaukti vietas.

## Komanda

- Povilas – organizatoriaus dalis: veiklų kūrimas, redagavimas ir vietų užimtumo valdymas.
- Jurgita – dalyvio dalis: veiklų peržiūra, rezervavimas ir rezervacijų atšaukimas.

## Technologijos

- Next.js
- Supabase
- GitHub
- Vercel
